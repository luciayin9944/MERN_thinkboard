# ThinkBoard_App


## 🔐 Features
- Full-Stack App Built with the MERN Stack (MongoDB, Express, React, Node)
- Full CRUD operations for Note.
- Build and Test a Fully Functional REST API

## 🛠️ Set Up
### .env
```bash
    MONGO_URI=<your_mongo_uri>

    PORT=5001
    NODE_ENV=development
```

### Run the Backend
```bash
    cd backend
    npm install
    npm run dev
```

### Run the Frontend
```bash
    cd frontend
    npm install
    npm run dev
```
